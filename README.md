# FLARE @ Google Summer of Code 2025
This repository contains information about Mandiant FLARE's participation in the Google Summer of Code 2025.

See our [GSoC Organization and Projects page](https://summerofcode.withgoogle.com/programs/2024/organizations/flare) for details on what we accomplished last year.
Also, [@fariss](https://github.com/fariss) published a post on Google Cloud's Threat Intelligence blog: [capa Explorer Web: A Web-Based Tool for Program Capability Analysis](https://cloud.google.com/blog/topics/threat-intelligence/capa-explorer-web-program-capability-analysis).

For those interested in applying, we have a non-exhaustive list of [project ideas](./doc/project-ideas.md) and [contributor guidance](./doc/contributor-guidance.md). When you have a question, reach out by creating a new topic in [GitHub discussions](https://github.com/mandiant/flare-gsoc/discussions) and mentioning @mandiant/flare-gsoc.

See you this summer!
